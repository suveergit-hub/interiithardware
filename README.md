Clue Chain Hunt Solver - Inter IIT Tech Meet 15.0This repository contains the complete autonomous multi-robot solution for the Inter IIT Tech Meet 15.0 Hardware Bootcamp challenge. The system enables a leader robot to autonomously navigate an unknown arena, decode a chain of visual clues, and locate a hidden treasure, while a camera-only follower robot safely tracks the leader's trajectory.   System OverviewThe project relies on a two-robot architecture operating in Gazebo Fortress:   Leader Robot: Equipped with a 360° LiDAR, RGB camera, and IMU. It maps the environment using slam_toolbox, navigates using Nav2, detects clue boards via OpenCV, and decrypts the next location.   Follower Robot: Equipped only with an RGB camera and wheel odometry. It utilizes a custom Pure Pursuit algorithm and breadcrumb tracking to follow ArUco Tag ID 49 mounted on the leader's back, maintaining a strict 0.6–2.0 meter following distance.   FeaturesAutonomous Clue Hunting: Chains visual perception (ArUco DICT_4X4_50 + QR decoding) to Nav2 actions without human intervention.   Dynamic Pillar Detection: Uses HSV color masking and LiDAR ranging to identify red, green, and blue pillars at runtime.   Cryptographic Validation: Validates decoy and look-alike boards by checking the QR code token against the SHA-1 hash of the previous valid clue.   Robust Follower Control: Features a feed-forward proportional controller and multi-threaded breadcrumb tracking. The follower predicts corner apexes and smoothly slows down during sharp turns even when the leader temporarily leaves the camera's Field of View.PrerequisitesOS: Ubuntu 22.04   ROS Distribution: ROS 2 Humble   Simulator: Gazebo Fortress   Dependencies: OpenCV (cv_bridge), nav2_bringup, slam_toolbox, tf2_ros, ros_gz_bridge   InstallationSource your ROS 2 installation:Bashsource /opt/ros/humble/setup.bash

UsageLaunch the Simulation:Start the Gazebo practice world and spawn the robots:Bashsource install/setup.bash
ros2 launch clue_hunt_gazebo sim.launch.py
Run the Mapping & Navigation Stack:Launch SLAM and Nav2:Bashros2 launch clue_hunt_navigation navigation.launch.py
Start the Autonomous Hunt:Execute the master launch file to start both the leader and follower nodes:Bashros2 launch clue_hunt_solver hunt.launch.py
Package Structureclue_hunt_gazebo: Contains the simulation world, models (decoy boards, treasure), and robot URDFs.   clue_hunt_navigation: Contains configuration YAML files for slam_toolbox and nav2, plus RViz2 configurations.   clue_hunt_solver: Contains the core autonomy Python nodes:hunt_node.py: Manages the leader's state machine, TF2 pose estimations (solvePnP), and dynamic pathfinding.   follower_node.py: Manages the follower's vision-based pure pursuit and breadcrumb trailing algorithm.common.py: Shared utilities for OpenCV conversions, ArUco detection, and quaternions
